# Peek

A simple dependency analysis tool that checks your project's `package.json` and `package-lock.json` for outdated packages, version conflicts, deprecated dependencies, and known security vulnerabilities.

## Features

- Drag and drop file uploads.
- Supports `package.json` and `package-lock.json`.
- Checks installed and latest package versions.
- Detects dependency conflicts and deprecated packages.
- Scans for known vulnerabilities using OSV.
- Search and filter dependencies.

## Getting Started

Clone the repository:

```bash
git https://github.com/abduli-mp/peek
cd peek
```

Install dependencies:

```bash
bun install
```

Start the development server:

```bash
bun dev
```

Open the local URL displayed in your terminal.
